# Online Exam Portal

## Overview
A comprehensive web application for conducting online exams, supporting multiple subjects and users. This portal streamlines the examination process, offering secure, efficient, and user-friendly features.

---

## Features

- **Secure User Authentication**: Uses JWT and bcrypt for password hashing.
- **Responsive UI**: Built with React to provide an intuitive interface for managing and taking exams.
- **RESTful APIs**: Efficient backend operations to manage users, subjects, questions, tests, and results.
- **Performance Tracking**: Students can view their test history and detailed performance metrics.
- **Scalability**: Designed to handle multiple users and subjects seamlessly.

---

## Technology Stack

- **Frontend**: React.js
- **Backend**: Node.js, Express.js
- **Database**: MySQL
- **Authentication**: JWT, bcrypt
- **Hosting**: AWS / Heroku

---

## Installation

### Prerequisites
- Node.js installed
- MySQL installed and running
- A web browser

### Steps

1. Clone the repository:
   ```bash
   git clone https://github.com/pranay435/Online-Exam-Portal-Backend.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Online-Exam-Portal-Backend
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the server:
   ```bash
   npm start
   ```

5. Access the application:
   ```
   http://localhost:3000
   ```
